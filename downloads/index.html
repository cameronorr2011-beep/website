RASPBERRY PI · LINUX ARM64

Algaephyte for Pi 3 B+

Requires 64-bit Raspberry Pi OS Desktop, Bookworm or newer. Extract the ZIP, read READ-ME.md, then run bash Algaephyte/install-pi.sh as your desktop user.

Download Raspberry Pi ZIP

121 MiB · Linux ARM64 · 32-bit Raspberry Pi OS unsupported

Python 3 and documented desktop libraries are required. Sensors need verified wiring and calibration. Hardware assignments are deliberately unconfigured by default.

Research preview — monitoring only

Includes live sensor states, local SQLite history, culture and experiment records, calibration, CSV export, backups and optional Groq interpretations. No pumps, heaters or dosing systems can be actuated. The Windows app was launch-tested; the ARM64 build was packaged and inspected but physical Pi operation, sensor accuracy and Pi performance have not been validated.

Optical density is a growth proxy, not calibrated biomass. AI conclusions are hypotheses, not verified findings. The included READ-ME.md documents deployment, safety, backups and remaining limitations.
