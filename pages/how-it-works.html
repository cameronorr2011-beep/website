The fleet learns; your data stays yours

Honest framing

Federated learning reduces data exposure; it is not a privacy guarantee. Update packets contain learned parameters that can leak information under adversarial analysis, and the aggregation server is a trust point. Standard cryptanalysis assumptions and your own threat model apply.

Offline behavior

Each node keeps a deterministic rule-based controller that maintains the climate within safe bands when the network is unreachable. On reconnect, telemetry replays first, then the node requests the latest aggregated model â€” and publishes its own pending update.
