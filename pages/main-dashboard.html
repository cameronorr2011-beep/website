The Mind Inside the Reactor

MAIN is an AI system that lives alongside the culture. It reads six sensors continuously — pH, temperature, light intensity, optical density, dissolved oxygen, and TDS — and feeds them into a Droop-model digital twin. That twin predicts growth before anything moves. A LangGraph AI pipeline (Gemini for deep biological reasoning, Groq for fast structured decisions) proposes the next action. A two-layer safety gate — deterministic hard limits plus twin simulation — blocks any action that would harm the culture. All of it open-source, running on a Pi Zero 2W.

It Senses

pH, temperature, light (BH1750), optical density (TSD-10), dissolved oxygen, and TDS — six analog channels through an MCP3008 ADC, plus an optional ESP32-CAM for microscope-grade vision.

02

It Predicts

Droop cell-quota kinetics. Steele photoinhibition. Beer-Lambert self-shading. A physics-based twin forecasts growth before a single pump moves — simulating each dose in silico first.

03

It Protects

Every action passes a two-layer safety gate. Deterministic hard limits first. Then a 24-hour twin simulation. If growth dips below threshold, the action is blocked. It fails closed. A physical e-stop sits behind it all.

04

It Learns

ChromaDB stores validated experiment outcomes. LangGraph retrieves similar past experiments for context. PhycoNet shares tuned twin parameters across reactors — never raw data — so the network gets smarter together.

    ph1 = env["ph"] + 0.06 * (value / volume_l)

Safety Architecture

Two-Layer Safety Gate — Fails Closed

Every AI proposal must pass deterministic hard limits, then a digital twin simulation. If either layer rejects, the action is blocked. A physical emergency stop on GPIO15 sits underneath as an independent backstop.

Layer 1

Hard Limit Validation

Deterministic rule check against configurable bounds: pH 8.5–10.5, temp 20–35°C, nutrient pulse ≤ 20mL, bicarbonate ≤ 5g, light 100–400 µE/m²/s. Unknown actions are rejected. Every check is pure logic — no AI, no ambiguity.

Layer 2

Digital Twin Simulation

Runs a 24-hour forward prediction using the Droop + Steele model. Any action predicted to cause negative or negligible growth (< 0.01/hr) is blocked. NaN/Inf values from sensor failures are caught and treated as unsafe — the gate fails closed.

PhycoNet

Federated Learning Across Reactors

Every 12 hours, each reactor shares its calibrated twin parameters (mu_max, I_opt, etc.) — never raw culture data. A weighted aggregator rejects outliers (>3σ) and publishes an improved global model. Every reactor gets smarter from the whole network, without exposing any private sensor readings.
