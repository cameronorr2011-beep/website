02 / The standard

The unit of trust is a source,
not a screenshot.

A claim without a record is only a rendering.

Orr Biologicals is built around provenance. Every record carries its source, version and limits alongside the result, so what was measured stays separate from what was computed.

We keep measured observations, curated metadata, computational models and predictions in separate evidence classes. These are research concepts in development; when a value is missing, the interface says DATA UNAVAILABLE rather than estimating a number and presenting it as biology.

03 / How we work

Research is a
chain of custody.

The platform is a record of what was measured, what was computed and what remains unknown. That distinction is part of the product, not a disclaimer added at the end.

01

Start with the source.

Dataset, version, query, table and retrieval time precede interpretation. A root id is not portable across versions without a mapping.

02

Separate observation from inference.

Measured observations come from instrumented pipelines. Curated labels and model predictions retain their own evidence state.

03

Publish the limit with the result.

An automated detector is not a complete manual curation. A model is not a measurement. A page that hides either is not finished.
