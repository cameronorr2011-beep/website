Orr Biologicals / Neuroscience

One neuron is a start.
Not the whole brain.

NeuroML is a provenance-first connectomics environment. Its first working record is one proofread MICrONS mouse V1 neuron, with the dataset's own skeleton and every detected synaptic partner. The fruit-fly connectome is a separate integration, not a number we borrow for a screenshot.

Shared method.

02 / Evidence boundary

The distinction is
the interface.

A predicted edge is not a measured synapse.
Verified observation

The MICrONS skeleton, its proofreading status and every synapse returned by synapses_pni_2 at version 1926.

Dataset annotation

The L5NP cell-type label comes from a dataset classifier. The page names it as an annotation rather than upgrading it to manual ground truth.

Not present

No mouse activity prediction, no fly graph and no validated model experiment is shown as live. DATA UNAVAILABLE is a valid result; an estimate presented as biology is not.

03 / What comes next

Build coverage.
Keep the limits.

The next mouse milestone is a small set of proofread neurons at one pinned version, followed by a real connectivity graph. The next fly milestone is an audit of the existing viewer against a specific published release. The public API remains a contract, not a live endpoint.
